# Worked example — `example-steady-habits`

The spec's Phase 5 dry run, produced on 2026-08-27 in the main session: an **invented** Capacitor + React
habit-tracker for anxious university students, deliberately not any real project (it is not habitforge).
Every interview answer is a stated assumption, marked in the decision log, because no owner answered live.
Nothing here enters the real voice registry.

What it shows: a complete `docs/story/` folder as `/story-init` leaves it, plus one on-voice draft
(`drafts/onboarding.md`) that passes the lint hook (`posttooluse-story-lint.sh`) and the humanize rubric.
Copy the *shape*, never the words — the words belong to a project that does not exist.
