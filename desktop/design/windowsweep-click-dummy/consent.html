First run

windowsweep collects usage data to improve the product for everyone.

The cleanup engine makes zero network calls – its own test suite asserts that, and that does not change. What follows is only about the desktop window you are looking at.

Never sent: a file path, a folder name, a drive label, your user name, your machine name, or the contents of anything. A run summary is a count and a number of bytes.

What the window sends, in plain terms Details

Which screens you opened and which buttons you pressed. A recording of this window with every piece of text masked. A stack trace when something breaks, with file paths stripped out.

There is no switch for this and no setting to find. This is how windowsweep gets better for the next person who runs it.
