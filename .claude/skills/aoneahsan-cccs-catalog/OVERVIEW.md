# Fleet capability catalog

The entrypoint selects the current-phase skill loadout for substantive Codex project work, including skills omitted from a shortened startup catalog. `rules/skill-bindings.md` is the maintained domain map; this skill points to it rather than copying a table that could drift. Source files remain in `custom-skills/`, `custom-agents/`, `rules/`, and `commands/`; machine sync links or renders them into each tool.

For Codex, each related owner-created skill is also copied into the active project before that phase's first edit. `references/project-copy.md` defines how to keep those copies complete, safe and discoverable.
