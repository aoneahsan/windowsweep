# Surface — social posts

A social post is a hook with a payoff attached. One idea, one CTA, the project's single main link. Social
content lives in the notebook only, never in a project repo (`~/.claude/rules/portfolio-and-social.md`).

## Shape per platform

| Platform | Hook window | Length | Notes |
|---|---|---|---|
| X | the first line | ≤ 280 chars per post; a thread is 4–7 posts | one post = one beat; the last post carries the link |
| LinkedIn | the first ~210 characters (before "see more") | 600–1,300 chars | line breaks every 1–2 sentences; no hashtag wall |
| Instagram / Threads caption | the first ~125 characters | ≤ 2,200 chars, usually far less | the image is the hook; the caption is the payoff |
| Reddit / forums | the title | as long as it is useful | no self-promotion tone; answer first, link last, if at all |

Hashtags: ≤ 3, specific, at the end. Emojis: only if the Bible's palette allows them, never as bullets.

## Structure

In medias res (`frameworks.md`): a specific instant or number in the first line. Then 3–5 beats joined by
"therefore/but". Then the payoff (the thing the hook promised). Then one CTA — a question, or the link. A
thread's first post must stand alone; a reader who sees only it should still get something.

## Voice

The palette's dominant band, more concentrated than anywhere else — a post is too short for minority bands
except as the last line. Burstiness in miniature: one long line, one short. The owner's personal voice for
posts in his name (`aoneahsan-cccs-story-personal-voice`); the project's voice for posts in the product's
name; never a blend.

## Images

Every social image carries the project's single main link as one clear CTA, from an SVG master
(`~/.claude/rules/portfolio-and-social.md`, `~/.claude/rules/frontend-ui-standards.md` §6).

## Traps

- Two hooks in one post — pick one.
- Engagement bait ("agree?", "thoughts?") with nothing behind it — a real question or none.
- A number without a source, a claim about users the product cannot count.
- Cross-posting one text unchanged to every platform — the hook window differs, so the first line must.
- Scheduling and publishing mechanics belong to `aoneahsan-cccs-social-platform-apis`, not to the draft.
