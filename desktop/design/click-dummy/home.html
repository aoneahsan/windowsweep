Developer mode

on

Package, build and test-runner caches you have used in the last 100 days are kept, and the newest version of every tool cache survives. Turn it off and those caches are cleared completely.

What it will never touch

  • - Documents, Pictures, Desktop, and every cloud-synced folder
  • - Browser profiles: logins, cookies, history, bookmarks, extensions
  • - Credentials and keys: .ssh, .gnupg, .aws, .secrets
  • - Toolchains: nvm, npm globals, corepack, cargo, Go
  • - Junctions and symlinks are removed as links, never followed

No flag bypasses this list, and it only ever grows.
